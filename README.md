# daily-build-oss — habit hub

Goal: daily coding habit, mixed learning, 2+ hrs/day, advanced.
Cadence: Mon/Tue build (web/API), Wed OSS small PR, Thu/Fri build (Python/full-stack), Sat OSS feature, Sun polish + writeup.
Daily flow:
1. git pull
2. 2hr timebox
3. commit + push same day (never backdate)
4. log 5 min in ACTIVITY.md
5. EOD 10-min OSS inbox review (see oss/EOD-CHECKLIST.md)
Miss-day: never fake dates, continue next day, Sunday catch-up for polish only.
Blocked OSS: fallback to local repro + docs/test PR in home repo.
Board: GitHub Projects Todo/Doing/PR Open/Merged/Showcased, move card daily.
